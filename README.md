# 🖥️ AI-Powered IT Log Analyzer & Dashboard

An intelligent log analysis and system monitoring web application built with **Streamlit** and **Machine Learning (Scikit-Learn)**. This tool helps System Administrators and DevOps engineers quickly parse server log files, detect recurring errors, classify log messages using AI, and generate instant troubleshooting recommendations.

---

## 🚀 Key Features

- **AI-Powered Classification:** Automatically classifies log messages using a trained machine learning model.
- **Interactive Dashboard:** Provides real-time metrics for total logs, errors, warnings, and info messages.
- **System Health Status:** Evaluates overall system risk levels based on error frequencies.
- **Automated Troubleshooting:** Matches common errors with actionable solutions and recommendations.
- **Report Export:** Allows users to download complete analysis reports in CSV format.

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit** (Web Interface & Dashboard)
- **Scikit-Learn / Joblib** (Machine Learning Model)
- **Pandas** (Data Processing & Manipulation)
